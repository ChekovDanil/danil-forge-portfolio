# Danil Forge — портфолио

Рабочая витрина продуктового дизайнера и разработчика Danil: семь отобранных кейсов в направлениях web, automation, UX/UI и Unity.

## Запуск

- `npm start` — `http://127.0.0.1:3070/`.
- `npm test` — структура витрины, наличие семи работ и изображений, HTTP-поведение и полное отсутствие закрытого проекта.

## Состав

1. Верста — пассажирский PWA и карты.
2. FieldDesk — CRM и диспетчерская.
3. ReportKit — обработка данных и экспорт.
4. Stockroom — административная панель каталога.
5. Relay — Telegram intake и маршрутизация.
6. Booking Desk — календарь и бронирование.
7. Release Dock — Docker и выпуск приложения.

## Граница публикации

1. Закрытые проекты и их материалы не включаются в публикацию.
2. До открытия репозитория локальные ссылки заменяются на стабильные внешние preview URL.
3. Публичный контакт добавляется только после отдельного решения владельца.
