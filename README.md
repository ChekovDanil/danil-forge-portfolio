# Danil Forge — портфолио

Публичная витрина продуктового дизайна и разработки. В основной подборке — шесть сильных работ с отдельными кейсами или интерактивными демо: Верста, FieldDesk, Booking Desk, Leadline, Groundlog и Batch Studio.

## Локальная проверка

- `npm start` — открыть витрину на `http://127.0.0.1:3070/`.
- `npm test` — проверить структуру, ссылки, статические файлы и HTTP-поведение.

Папка `public` полностью автономна и готова для GitHub Pages. Закрытые продукты и их исходники в эту публикацию не входят.
