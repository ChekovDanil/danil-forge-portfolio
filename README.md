# Главная витрина портфолио

Локальная редакторская страница из восьми отобранных кейсов. Внешняя публикация намеренно не выполняется до утверждения публичного имени, контакта и перечня разрешённых работ.

## Запуск

- `npm start` — `http://127.0.0.1:3070/`.
- `npm test` — структура витрины, наличие восьми работ и изображений, HTTP-поведение и защита конфиденциального названия.

## Состав

1. LOCUS — мобильный продукт и PWA.
2. Верста — пассажирский PWA и карты.
3. FieldDesk — CRM и диспетчерская.
4. ReportKit — обработка данных и экспорт.
5. Stockroom — административная панель каталога.
6. Relay — Telegram intake и маршрутизация.
7. Booking Desk — календарь и бронирование.
8. Release Dock — Docker и выпуск приложения.

## Перед внешней публикацией

1. Заменить временную метку `WORK / 2026` публичным именем или знаком.
2. Заменить служебную строку в подвале реальным публичным контактом.
3. Заменить локальные ссылки на стабильные внешние preview URL.
