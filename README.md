# Danil Forge — портфолио

Рабочая витрина продуктового дизайнера и разработчика Danil: восемь отобранных кейсов в направлениях web, automation, UX/UI и Unity.

## Запуск

- `npm start` — `http://127.0.0.1:3070/`.
- `npm test` — структура витрины, наличие восьми работ и изображений, HTTP-поведение и защита конфиденциального названия.

## Состав

1. LOCUS — мобильный продукт и PWA.
2. Верста — пассажирский PWA и карты.
3. FieldDesk — CRM и диспетчерская.
4. ReportKit — обработка данных и экспорт.
5. Stockroom — административная панель каталога.
6. Relay — Telegram intake и маршрутизация.
7. Booking Desk — календарь и бронирование.
8. Release Dock — Docker и выпуск приложения.

## Граница публикации

1. LOCUS показывает только обезличенные скриншоты закрытого продукта; приложение, сборка и исходники не публикуются.
2. До открытия репозитория локальные ссылки заменяются на стабильные внешние preview URL.
3. Публичный контакт добавляется только после отдельного решения владельца.
